# 笔写测试板（绘制模式）

用来在真实材料上验证这一周的改动：中文单线、标点、拼音声调、心形、中英混排行距。

- **工程文件**：[pen-test-plate.polycut](pen-test-plate.polycut) ← 在软件里打开就能看到图形在床上的位置
- 刀路文件：[pen-test-plate.gcode](pen-test-plate.gcode)
- 模式：**绘制**（笔），不是切割。**落笔 Z 5 / 抬笔 Z 10**，走刀 1 次
- 字号 **68 pt = 24 mm**（字号现在真的是 pt，1 pt = 0.3528 mm）
- 耗时：约 **3 分 30 秒**，总路径 2.38 m，120 次落笔

## 纸张：A5 和 A4 都放不下，需要裁

图形实际占用 **152 × 202 mm**（不含结尾退刀）。

| 纸 | 行不行 |
|---|---|
| A5（148 × 210） | ✗ 宽度差 4 mm |
| A4（210 × 297） | ✗ 长边 297 超过床的 256，放不进床 |
| **从 A4 裁一块 165 × 215** | ✓ 推荐 |

裁的时候留出 6 mm 余量即可，图形本身不需要白边以外的空间。

## 位置：打开工程文件看，不要靠估

在 PolyCut 里「文件 → 打开」选 `pen-test-plate.polycut`，画布就是整张 256 × 256 的床，
**网格每格 10 mm**，数格子即可定位。

图形在画布上的范围：

| | 最小 | 最大 |
|---|---|---|
| X | 37.7 | 189.6 |
| Y（画布坐标） | 36.9 | 239.1 |
| Y（机床坐标） | 16.9 | 219.2 |

⚠️ **注意 Y 方向**：画布上的"上"对应床上 Y 大的那一侧（远端）。软件右下角有常驻提示。

纸贴好后，笔应该从纸的**左下角附近**开始。

> 上一次这份文档里写的 `X 3.8–175.3 / Y 57.0–229.3` 是错的，那是另一版布局的数据。
> 现在的数字是从 `pen-test-plate.gcode` 逐行统计出来的，和工程文件一致。

## 内容

```
陈伟♥林静              ← 中文单线 + 心形骨架
2026.5.20              ← 数字与小数点
李明。yuè             ← 中文标点（。在左下）+ 带声调的拼音
远见设计               ← 中文
YUAN STUDIO            ← 英文（Hershey 手写体）
                ┌───┐
                └───┘  ← 42.7×42.7 方框，用来量尺寸准不准
```

打开工程文件看到的**就是这个样子**——因为工程是从刀路反推的，软件里显示的就是笔将走的路径。

## 跑完之后会自动做什么

```
G91 / G1 Z10 F600 / G90     ← 先相对抬笔 10 mm（不会在纸上拖）
G1 X10 Y5 F3000             ← 退到左前角
M400                        ← 等运动完成
M1006 ... （打印机自带完成音效）
M18 X Y                     ← 只关 X/Y，Z 保持锁定
```

## 跑之前

1. 落笔是 **Z5**、抬笔 **Z10**。如果笔架需要别的压缩量，先在「工具配置」改「Z 高度 → 工作」再重新生成。
2. 纸用美纹胶带四面贴死。
3. 文件头是 `M104 S0 / M140 S0 / G21` + `G28` —— **会先关加热再回零**。确认笔架在回零路径上不会撞到东西。

## 跑完看这几件事

| 看什么 | 判断标准 |
|---|---|
| 「陈伟♥林静」 | 是不是一笔一笔写出来的，而不是空心描边 |
| 心形 | 是不是尖端朝下的正立心形 |
| 「李明。」的句号 | 应该在「明」的左下方，不是字的中间 |
| 「yuè」的 è | 字母上方应该有一道短斜线 |
| 五行之间的间距 | 是否均匀，有没有压行 |
| 方框 | 量一下是不是 42.7×42.7 mm，四个角是否方正 |

## 已知会看到的现象

- 打开工程文件看到的是**刀路**（单线笔画），不是系统字体的样子——这正是笔会画的。
- 中英混排时行距按 1.7 em 走，比纯英文宽一点，避免两种字体的行高差异把行压在一起。
