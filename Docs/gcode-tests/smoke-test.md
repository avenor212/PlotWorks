# 冒烟测试件：一次跑完起始 / 落笔 / 方向 / 结尾

这个件在纸上只占 **59 × 59 mm**，生成时间 **16 秒**。目的不是画得好看，是用最小的纸和最短的
时间把「从回零到松电机」整条链路走一遍，**并且能看出上下左右有没有翻**。

- 刀路：[smoke-test.gcode](smoke-test.gcode)
- 工程文件：[smoke-test.polycut](smoke-test.polycut)（打开就能看到位置）

---

## 图形：三个元素，任何一轴翻转都藏不住

```
┌────────────┐
│ ＼         ┌┐ │   ← 外框 59×59
│   ＼       └┘ │   ← 对角线：从上左到下右
│     ＼        │   ← 小方块：贴在右上角内侧
└────────────┘
```

**为什么不用正方形**：正方形上下翻转看不出来。上一版的方框就是这个毛病——它掩盖了方向问题。
现在只要看对角线的斜向和小方块落在哪个角，就能判定：

| 看到的样子 | 说明 |
|---|---|
| 对角线 ↖→↘，小方块在**右上** | 方向正确 |
| 对角线 ↙→↗，小方块在**右下** | Y 轴翻了 |
| 对角线 ↖→↘，小方块在**左上** | X 轴翻了 |
| 对角线 ↙→↗，小方块在**左下** | 两轴都翻 |

打开工程文件，画布就是整张 256 × 256 的床，**网格每格 10 mm**：图形大约在从左往右第 10 到
第 16 格、从上往下第 10 到第 16 格之间。纸至少 90 × 90 mm。

> **Y 方向约定**（按机床控制面板实测）：Y 值越大，床越靠近操作者。软件右下角有常驻提示。

## 这次改了什么

1. **起始 G-code 加了开机音效** —— 从你给的 `打印机起始G-code.txt` 原样照抄了那 18 行
   （`M1006 A0 B10 L100 C37...` 到 `M1006 W`），只删掉了末尾的 `M18`（会在回零前切断电机）。
2. **结束退刀方向修正** —— 原来 `G1 X10 Y5`（Y 小 = 床推到远侧），改成 `G1 X10 Y251`（床靠近你）。
3. **图形改成了不对称** —— 见上。

## 要盯的点

按发生顺序：

### 1. 开机音（`G28` 之前）

```
==== 开始提示音：机器马上要动了 ====
M17 / M400 S1 / M1006 S1
M1006 A0 B10 L100 C37 ... （18 行）
M1006 W
==== 回零 ====
G28
```

**听**：这次应该能听到和打印机开机时一样的旋律。**没响就告诉我**，说明 `M1006` 需要别的前置条件。

### 2. `G28` 回零

**看**：有没有异响或撞限位。

### 3. 第一次落笔（Z5）

**看**：笔尖接触纸的瞬间。太深（压痕）还是没画上？**记下纸和笔的类型**。

### 4. 方向（这次的重点）

按上面的表格看对角线和小方块。

### 5. 外框尺寸

尺子量应为 **59.2 × 59.2 mm**，四边闭合。

### 6. 结尾

```
G91 / G1 Z10 F600 / G90
G1 X10 Y251 F3000    ← 床应该朝你走来
M400
M1006 ...（结束音）
M18 X Y
```

**看**：床是不是**往你这边**走过来停下。这是本次改动最需要确认的一条。
**试**：能推动床，但 Z 不掉下来。
