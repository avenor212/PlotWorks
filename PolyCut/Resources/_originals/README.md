# 上游品牌原文件（依 GPL-3.0 保留，不是备份）

本目录存放上游 **PolyCut**（<https://github.com/IridiumIO/PolyCut>，作者 IridiumIO，GPL-3.0）的**原始**品牌资源：

| 文件 | 说明 |
|---|---|
| `banner_dark.svg.bak` | 上游 README 横幅 |
| `logo.svg.bak` | 上游图标（矢量） |
| `logo.ico.bak` | 上游图标（Windows 图标） |

本分支已换成 PlotWorks 自有品牌（`../logo.svg`、`../logo.ico`、`../banner_dark.svg`），这里保留上游原件是为了：

1. GPL-3.0 要求保留原作者的版权与许可声明，保留原文件是最直接的证据；
2. 将来若要核对"哪些是上游的、哪些是本分支改的"，有原件可比对。

**不要把 `.bak` 当成待清理的临时文件删掉。** 之所以沿用 `.bak` 后缀，是因为改名时就是这么存的；如果以后整理，建议改名为 `upstream-*.orig`，并同步更新 `Docs/rename-debt.md` 里的记录。
